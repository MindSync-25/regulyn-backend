# Architecture Diagrams

Visual documentation of system architecture and design.

## Diagram Types

### System Context (C4 Level 1)
- Overall system landscape
- External actors and systems
- High-level boundaries

### Container Diagram (C4 Level 2)
- Service boundaries
- Infrastructure components
- Communication protocols

### Component Diagrams (C4 Level 3)
- Internal service structure
- Component interactions
- Technology choices

### Data Flow Diagrams
- Data processing flows
- Event flows
- Integration patterns

## Tools
- PlantUML
- Draw.io
- Mermaid
- Lucidchart

## Naming Convention
- `system-context.png` - System context diagram
- `container-diagram.png` - Container/service diagram
- `service-<name>-component.png` - Component diagrams per service
- `data-flow-<workflow>.png` - Data flow diagrams
