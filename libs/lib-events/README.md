# lib-events

Event-driven architecture support library.

## Purpose
- Kafka producer/consumer abstractions
- Event schemas and models
- Event serialization/deserialization
- Event versioning
- Dead letter queue handling

## Features
- Domain event base classes
- Event publishing utilities
- Event listeners
- Schema registry integration
- Retry mechanisms

## Event Categories
- Identity events
- Consent events
- DSAR events
- Audit events
