# lib-observability

Monitoring, logging, and tracing library.

## Purpose
- Structured logging
- Distributed tracing
- Metrics collection
- Health checks
- Performance monitoring

## Features
- Custom logging annotations
- MDC context propagation
- OpenTelemetry integration
- Prometheus metrics
- Health check endpoints

## Stack
- Logback/SLF4J
- Micrometer
- OpenTelemetry
- Spring Boot Actuator
