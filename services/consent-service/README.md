# Consent Service

Manages user consent for data processing in compliance with DPDP Act.

## Purpose
- Record and manage user consents
- Consent lifecycle management
- Consent verification and validation
- Consent withdrawal processing

## Tech Stack
- Java 21
- Spring Boot 3
- PostgreSQL
- Kafka (events)
- Temporal (workflows)

## Dependencies
- lib-common
- lib-events
- lib-temporal
- lib-observability
