# DSAR & Grievance Service

Data Subject Access Request and grievance handling service.

## Purpose
- Process DSAR requests (access, correction, erasure)
- Grievance submission and tracking
- Request workflow orchestration
- Response generation

## Tech Stack
- Java 21
- Spring Boot 3
- PostgreSQL
- Temporal (workflows)
- Kafka (events)

## Dependencies
- lib-common
- lib-events
- lib-temporal
- lib-observability
