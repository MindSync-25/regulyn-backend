# Identity & Tenant Service

Identity management and multi-tenant configuration service for DPDP compliance platform.

## Purpose
- User authentication and authorization
- Tenant onboarding and management
- Role-based access control (RBAC)
- Session management

## Tech Stack
- Java 21
- Spring Boot 3
- PostgreSQL
- Redis (caching)
- Kafka (events)

## Dependencies
- lib-common
- lib-auth
- lib-events
- lib-observability
