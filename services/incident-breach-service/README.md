# Incident & Breach Service

Security incident and data breach management service.

## Purpose
- Record and track security incidents
- Data breach notification workflow
- Impact assessment
- Regulatory reporting

## Tech Stack
- Java 21
- Spring Boot 3
- PostgreSQL
- Temporal (workflows)
- Kafka (events)

## Dependencies
- lib-common
- lib-events
- lib-temporal
- lib-observability
