# Retention & Deletion Service

Data retention policy enforcement and automated deletion workflows.

## Purpose
- Define and enforce retention policies
- Scheduled data deletion
- Retention compliance monitoring
- Audit trail for deletions

## Tech Stack
- Java 21
- Spring Boot 3
- PostgreSQL
- Temporal (workflows)
- Kafka (events)

## Dependencies
- lib-common
- lib-events
- lib-temporal
- lib-observability
